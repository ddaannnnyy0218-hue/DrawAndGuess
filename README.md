# 画里有话 · Draw & Guess

浏览器绘画对战游戏。默认三人段位桌，轮流一人画、两人猜。青铜以练习对手热身，白银起优先真人，不足时补同级练习对手。

## 当前玩法

- **单词题库**：338 个独立词语；已撤下所有自动组合的故事题。六个主题词包，支持 3–100 题好友自定义词库。进阶词不进入青铜排位。
- **三人排位**：每人画一次，共三幅，每幅 55 秒。猜词 80–300 分，越早猜中越高；画手每让一人猜中得 50 分。第一人猜中后最多保留 22 秒追答，计分仍按原始题目时长。
- **自动衔接**：选词超时自动选；揭晓 2.8 秒后自动下一幅，没有准备按钮。整局结束 8 秒后可自动再匹配，连续对局开关可暂停；浏览器不可见时不自动开下一桌。
- **有依据的机器人猜词**：根据已画出的笔画、公开类别与字数观察、试探、反应及作答。熟悉度不再永久阻止回答，候选改变不会无限延迟输入。参数固定，不在局内按真人输赢强制胜负。
- **反应式补画**：轮廓 → 关键细节 → 第二幅同词示意。仍有人未猜中才触发后续；揭晓冻结实际画面，不展示未来笔画。素材为 345 类共 8,280 份真实手绘记录。
- **对手资料**：自然昵称、不重名；不在名字中拼接性格标签，练习对手身份仍可查询。排位匹配规则说明真人与电脑混合方式。
- **只画图，不写字**：答案、拼音、字母缩写与拆字提示均违规。两位猜词者共同举报后取消本幅计分。没有中文 OCR，尚不能自动判断所有手写文字。
- **技能与画笔**：线索卡、排除卡、灵感卡；签字、荧光、双线、彩虹、星点、像素六种笔触，颜色、粗细、橡皮、撤销、PNG 保存与 B / E / Ctrl 或 ⌘ Z / [ / ] 快捷键。
- **好友玩法**：经典画猜、三笔挑战（2–8 人）、假答案俱乐部（3–8 人，编答案 → 投票 → 揭晓）。异步挑战可生成 7 天有效链接。

免费提示逐步出现，接近答案的反馈只发给本人。排位保存最近 900 个候选题与 300 个画稿来源，合并同桌真人的历史，优先避重，题池用完优先回收更早的题目。好友房间也有跨局题目记忆。

## 段位与结果

| 段位 | RP 门槛 | 优先真人等待 |
| --- | --- | --- |
| 青铜 | 0 | 直接练习桌 |
| 白银 | 200 | 8 秒 |
| 黄金 | 500 | 12 秒 |
| 铂金 | 900 | 15 秒 |
| 钻石 | 1400 | 18 秒 |
| 大师 | 2000 | 20 秒 |

全真人桌独占第一 +50，混合桌独占第一 +40；并列第一且有得分 +20，第二且有得分 +10；末名全真人桌 −25、混合桌 −15。青铜负分受保护，零分不奖励。弃赛者单独结算，其他人继续；失联宽限 45 秒。旧版组合题局升级时取消，不扣 RP。

段位与成绩在 D1 保存，身份凭证在当前浏览器；尚无跨设备账号绑定。当前举报不等同于完整反作弊。

## 技术与验证

React 19 / TypeScript / Vinext / Cloudflare Worker / D1。

| 文件 | 职责 |
| --- | --- |
| `lib/ranked.js` | 排位队列、回合、自动时钟、计分与举报 |
| `lib/bot-players.js` | 独立性格、视觉假设、反应及分阶段手绘回放 |
| `lib/game-balance.js` | 六档参数与计分曲线 |
| `lib/vocabulary.js` / `lib/lexicon.tsv` | 单词题库、别名、难度与提示 |
| `lib/doodle-judge.js` | 实际 DoodleNet CPU 视觉模型 |
| `components/ranked-hub.tsx` | 连续对局、画猜、规则、资料与技能 |
| `components/rank-badge.tsx` | 六套不同轮廓的段位徽章 |
| `lib/game.js` / `lib/challenges.js` | 好友房间与异步挑战 |
| `db/schema.ts` / `drizzle/` | 数据模型与不可变迁移 |
